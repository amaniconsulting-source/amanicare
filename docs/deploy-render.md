# Deploy on Render

The app runs as one Docker web service; all data (bill photos included) lives in PostgreSQL (Neon).
`render.yaml` describes the service.

1. Sign up at <https://render.com> with **GitHub**, and allow Render to access
   `amaniconsulting-source/amanicare`.
2. **New → Blueprint**, pick the repository (branch `develop`). Render reads `render.yaml`.
3. Fill in the values it asks for, copied from your `.env`: `DATABASE_URL` (Neon pooled string),
   `ADMIN_PHONE`, `ANTHROPIC_API_KEY`, the four `WHATSAPP_…` values, and `SENTRY_DSN` (may stay empty).
4. **Apply**. The first build takes a few minutes. The address is shown at the top of the service,
   e.g. `https://amanicare.onrender.com`. `BASE_URL` is set automatically from it.
5. Open the address: the browser asks for a password. The user name can be anything; the password
   is `SITE_PASSWORD` under **Environment** (generated by Render).
6. In Meta: set the privacy policy URL to `https://<address>/privacy.html`, and the WhatsApp webhook
   to `https://<address>/api/webhooks/whatsapp` (same verify token).

Every push to `develop` redeploys automatically. Migrations run at startup.

## Before real users

- `OTP_DEV=0` and remove `SITE_PASSWORD` (login codes must arrive by WhatsApp: needs Meta business
  verification and the `amanicare_login_code` template, or an SMS provider).
- `plan: starter` (no sleeping), a separate Neon branch or project for production, `SENTRY_ENVIRONMENT=production`.
- A separate `amanicare-prod` Anthropic key and a permanent WhatsApp system-user token.
